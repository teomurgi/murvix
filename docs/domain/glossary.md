# Candidate ubiquitous language

[Domain reference](README.md) · [Model](domain-model.md) · [Context map](context-map.md)

This is an extracted vocabulary, **not** evidence of agreement among domain experts. **Observed** means the named artifact uses or implements the meaning. Context-qualified terms intentionally preserve differences.

| Term | Context-qualified meaning and aliases | Evidence and uncertainty |
| --- | --- | --- |
| Profile | The local configuration/state namespace used by an app/server installation; not an authenticated user account. | **Observed — documented usage:** profile folders and sockets in [docs/tech/architecture.md:158–166](../tech/architecture.md#L158-L166); **Not established:** an account/tenant model. |
| Server | Authority for its catalog, terminal sessions, retained output and server-side operations. A configured client endpoint is not the same identity as the responding server. | **Observed:** server identity checks in `AppState::apply_catalog`, [crates/murvix-app-core/src/catalog.rs:214–238](../../crates/murvix-app-core/src/catalog.rs#L214-L238). |
| Server identity / server ID | `ServerIdentity` identifies the server's catalog; app-core `ServerId` identifies a local/remote endpoint within client state. Local has a fixed `ServerId`. | **Observed:** [crates/murvix-protocol/src/project.rs:67–71](../../crates/murvix-protocol/src/project.rs#L67-L71), [crates/murvix-app-core/src/ids.rs:43–56](../../crates/murvix-app-core/src/ids.rs#L43-L56). Conflating these would hide changed/duplicate-server detection. |
| Project — server | An independently identified registration of a primary directory, name, icon/logo/color, optional kind/parent, and extra workspace roots. | **Observed:** `ProjectDescriptor` in [crates/murvix-protocol/src/project.rs:87–116](../../crates/murvix-protocol/src/project.rs#L87-L116). Directory equality is not identity equality. |
| Project — desktop | A cached server descriptor plus client-owned tabs/groups, local creation metadata and availability state. | **Observed:** [crates/murvix-app-core/src/project.rs:70–105](../../crates/murvix-app-core/src/project.rs#L70-L105). Not a second server-side registration. |
| Project — TUI | Local layout state indexed by the server's `ProjectId`; contains tabs and an active tab index, not a duplicate directory catalog. | **Observed:** [crates/murvix-cli/src/state.rs:18–50](../../crates/murvix-cli/src/state.rs#L18-L50). |
| Workspace | A project's primary directory followed by extra roots, used as agent context. Also used informally for the whole desktop product. | **Observed:** `Project::workspace`, [crates/murvix-app-core/src/project.rs:124–132](../../crates/murvix-app-core/src/project.rs#L124-L132); broader product use in [README.md:13](../../README.md#L13). Extra roots do not make a project available if its primary folder is missing. |
| Home | Built-in project representing a server user's home directory; the local Home leads the client project list. A remote Home stands for that remote server in navigation. | **Observed:** [crates/murvix-app-core/src/home.rs:10–89](../../crates/murvix-app-core/src/home.rs#L10-L89), [crates/murvix-app-core/src/project.rs:137–140](../../crates/murvix-app-core/src/project.rs#L137-L140). |
| Worktree | In Git, a checkout folder/branch relationship; in the catalog, a child project whose `kind` is `Worktree` and whose parent is a normal project. | **Observed:** [crates/murvix-protocol/src/project.rs:79–85,173–189](../../crates/murvix-protocol/src/project.rs#L173-L189). Translation and removal rules: [BR-03](business-rules.md#br-03-worktree-creation-and-removal). |
| Session / terminal | Server-owned terminal identity and execution/output lifecycle. A retained ended session is not a still-running process. | **Observed — documented distinction:** [docs/product/server-model.md:13–23,61–71](../product/server-model.md#L61-L71); implementation: [model](domain-model.md#terminal-session). |
| Pane — desktop | Identified local view containing a terminal reference, browser, or extension webview. `Settings` remains a deserialization/migration variant, not evidence of current settings-in-project UI. | **Observed:** [crates/murvix-app-core/src/pane.rs:6–20](../../crates/murvix-app-core/src/pane.rs#L6-L20); legacy settings-pane removal in [crates/murvix-app-core/src/state.rs:135–158](../../crates/murvix-app-core/src/state.rs#L135-L158). |
| Tab — desktop | Identified set of panes and split layout, optional custom title/color/pin, and optional zoomed pane. A layout-file leaf named `tab` actually creates a terminal pane. | **Observed:** [crates/murvix-app-core/src/tab.rs:41–53](../../crates/murvix-app-core/src/tab.rs#L41-L53), layout leaf building in [crates/murvix-app-core/src/project_layouts.rs:224–242](../../crates/murvix-app-core/src/project_layouts.rs#L224-L242). |
| Tab group | A local group selecting one of its tabs; multiple groups are arranged in their own split tree. Not a saved sidebar project group. | **Observed:** [crates/murvix-app-core/src/groups.rs:135–173,274–293](../../crates/murvix-app-core/src/groups.rs#L135-L173). |
| Layout | Either mutable client view state, its split tree, or an explicitly applied project configuration in `.murvix/layouts`. Desktop and TUI do not share one layout document. | **Observed:** [crates/murvix-app-core/src/store.rs:8–14](../../crates/murvix-app-core/src/store.rs#L8-L14), [crates/murvix-cli/src/state.rs:598–614](../../crates/murvix-cli/src/state.rs#L598-L614), [crates/murvix-app-core/src/project_layouts.rs:8–40](../../crates/murvix-app-core/src/project_layouts.rs#L8-L40). |
| Reference / attachment | A layout reference says a client still presents a session, including hidden panes; an attachment additionally streams its terminal surface. They are not equivalent to ownership or permission. | **Observed — documented distinction:** [docs/product/server-model.md:25–42](../product/server-model.md#L25-L42); implementation: [BR-05](business-rules.md#br-05-close-detach-and-session-references). |
| Owner | Session participation label for the earliest connected participating client; not exclusive input authority. | **Observed — documented policy:** [docs/product/server-model.md:34–40](../product/server-model.md#L34-L40); implementation evidence in [model](domain-model.md#terminal-session). |
| Close / detach / end / discard | Close changes a view and may request discarding an unreferenced session; detach removes a view without requesting termination; end terminates a session; discard includes removal of retained content. | **Observed:** distinct mutation paths in [crates/murvix-app-core/src/state.rs:628–687](../../crates/murvix-app-core/src/state.rs#L628-L687), orchestration in [crates/murvix-app/src/model.rs:1325–1391](../../crates/murvix-app/src/model.rs#L1325-L1391). Exact server consequences: [BR-05](business-rules.md#br-05-close-detach-and-session-references). |
| Catalog / revision / intent | Shared project snapshot; version marker for refetch; queued client mutation with an operation identity. An invalidation is not a durable record of every edit. | **Observed:** [crates/murvix-app-core/src/catalog.rs:139–179,214–264](../../crates/murvix-app-core/src/catalog.rs#L139-L179); `Message::Changed` in [crates/murvix-protocol/src/message.rs:15–40](../../crates/murvix-protocol/src/message.rs#L15-L40). |
| Creation token / operation ID | Identity used to correlate/replay an operation; a desktop pane derives its creation token from its own UUID. It is not a business event ID. | **Observed:** [crates/murvix-app-core/src/ids.rs:59–62](../../crates/murvix-app-core/src/ids.rs#L59-L62); delivery guarantees are scoped in [rules](business-rules.md). |
| Available / missing / offline | Missing concerns a primary folder (and worktree marker); offline concerns connection status. A disconnected remote is not marked missing merely for being offline. | **Observed:** [crates/murvix-app-core/src/project.rs:142–165](../../crates/murvix-app-core/src/project.rs#L142-L165), [crates/murvix-app-core/src/state.rs:280–286](../../crates/murvix-app-core/src/state.rs#L280-L286). |
| Agent activity / unread attention | Best-effort agent state and an acknowledgement-sensitive attention indication; not an authoritative agent job ledger. | **Observed — documented intent:** [docs/product/server-model.md:80–86](../product/server-model.md#L80-L86); implementation: [WF-04](workflows.md#wf-04-observe-and-acknowledge-agent-activity). |
| Composer / draft / submission | Project-scoped prepared terminal input, possibly with attachments, followed by delivery to selected terminals. A submission is not proof the terminal program accepted or completed a task. | **Observed — documented contract:** [docs/product/app-model.md:161–165](../product/app-model.md#L161-L165); implementation: [WF-06](workflows.md#wf-06-compose-and-deliver-terminal-input). |
| Extension / language pack | An installed workspace contribution; a language pack is a resource-only localization contribution rather than executable extension logic. | **Observed — documented distinction:** [docs/tech/architecture.md:143–154](../tech/architecture.md#L143-L154); enforcement: [BR-12](business-rules.md#br-12-extension-authority). |
| Browser pane | Desktop-hosted page/profile, distinct from a server terminal. CLI browser automation targets the app socket rather than the terminal server. | **Observed — documented ownership:** [docs/tech/architecture.md:156–166](../tech/architecture.md#L156-L166); implementation: [WF-08](workflows.md#wf-08-extend-or-automate-the-desktop-workspace). |
| Paired device / mobile access | Credential-based TLS client access and its management UI/CLI. `mobile` is a management command name, not proof a phone application ships. | **Observed — explicit scope:** [docs/product/server-model.md:88–118](../product/server-model.md#L88-L118); [BR-10](business-rules.md#br-10-connection-authority). |
| Capability — runtime | `Supported`, `Unsupported`, or `Unavailable(reason)` for a build/backend/service combination. A menu description does not prove local availability. | **Observed:** [crates/murvix-core/src/capability.rs:63–94,110–127](../../crates/murvix-core/src/capability.rs#L63-L94). |

**Not established:** a single agreed meaning of the overloaded words “workspace,” “project,” “tab,” and “layout” across product language, CLI state, layout files, and extension API. This reference qualifies them instead of silently normalizing them.
