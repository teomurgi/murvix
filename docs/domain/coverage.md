### Terminal interaction detail

**Observed:** desktop selection uses terminal cell spans, expands overlapping wide runs and extracts trimmed rows; IME holds marked text until committed to live terminal input. Paste normalizes newlines, strips embedded escape introducers, quotes absolute dropped paths and applies bracketed-paste mode. Image paste can send Ctrl-V for the foreground program to consume clipboard. Search requests include query/case/cursor and reject stale replies. These are distinct from claiming the shell accepted the input. Evidence is in the terminal row above. Native screen painting, clipboard authorization, and live shell integration were not run.

**Observed:** live prompt navigation/command-output selection uses semantic prompt coordinates, requests older history pages when the prior prompt is not loaded, and selects rows between prompt boundaries. Next-prompt navigation falls back to the bottom when no next prompt exists. Archived output does not preserve these live annotations. [crates/murvix-app/src/views/terminal/pane.rs:530–604](../../crates/murvix-app/src/views/terminal/pane.rs#L530-L604), [crates/murvix-app/src/views/terminal/scroll.rs:291–391](../../crates/murvix-app/src/views/terminal/scroll.rs#L291-L391); archive limit: BR-06.
