# Business rules and implementation constraints

[Domain reference](README.md) · [Workflows](workflows.md) · [Model](domain-model.md)

These stable IDs distinguish user policy, implementation safeguards, persistence constraints and unexecuted test expectations. **Observed** refers to inspected code, not executed behavior. No rule below implies protection from arbitrary external filesystem/process writers.

## BR-01 Project identity and Home

**Observed — structural policy:** each catalog has exactly one Home matching its stored Home ID; Home cannot be deleting. Project map keys must match descriptor identities; every session membership must name an existing project. Parents must exist and cannot be Home, children, or kind-bearing projects. Ordinary registration rejects duplicate identities, **not duplicate directories**. Deleting a normal project marks its direct children too, ends/discards memberships and removes registrations; ordinary deletion leaves project folders on disk.

Enforcement: `State::validate`, `validate_parent`, mutation/delete cleanup, [crates/murvix-server/src/catalog/mod.rs:103–144](../../crates/murvix-server/src/catalog/mod.rs#L103-L144), [crates/murvix-server/src/catalog/mutations.rs:8–139](../../crates/murvix-server/src/catalog/mutations.rs#L8-L139), [crates/murvix-server/src/registry.rs:240–255](../../crates/murvix-server/src/registry.rs#L240-L255). Desktop Home ordering/removal protections: [crates/murvix-app-core/src/state.rs:410–451,1035–1068](../../crates/murvix-app-core/src/state.rs#L410-L451). **Limit:** client projections and queued deletion are not immediate global deletion. Unexecuted duplicate-directory/deletion scenarios: [crates/murvix-server/tests/projects.rs:62–112,209–233](../../crates/murvix-server/tests/projects.rs#L62-L112).

## BR-02 Workspace roots and availability

**Observed — validation/scope:** a descriptor needs an absolute, NUL-free primary path of at most 4096 bytes; extra roots are distinct absolute paths, exclude the primary, and are limited to 16 roots/16 KiB total. Ordinary registration checks directories exist. Desktop worktree extra-root editing is refused; ordinary extra roots are agent context, not independently owned projects. Local availability checks the primary directory and, for worktrees, a `.git` file; missing extras do not block a project. Offline remote status is not inferred to be missing.

Enforcement: [crates/murvix-protocol/src/project.rs:173–234](../../crates/murvix-protocol/src/project.rs#L173-L234), [crates/murvix-server/src/catalog/mutations.rs:106–169](../../crates/murvix-server/src/catalog/mutations.rs#L106-L169), [crates/murvix-app-core/src/project.rs:142–165](../../crates/murvix-app-core/src/project.rs#L142-L165), [crates/murvix-app-core/src/state.rs:280–286,380–408](../../crates/murvix-app-core/src/state.rs#L380-L408). **Bypass/limit:** Git completion inserts descriptors through a separate catalog path, so ordinary-registration existence checks are not universal catalog invariants: [crates/murvix-server/src/catalog/git.rs:72–99](../../crates/murvix-server/src/catalog/git.rs#L72-L99). Workspace roots are captured into session environment at spawn, not proven to update every running agent after a metadata edit: [crates/murvix-server/src/spawn.rs:22–120](../../crates/murvix-server/src/spawn.rs#L22-L120).

## BR-03 Worktree creation and removal

**Observed — lifecycle policy:** creation/registration requires an ordinary top-level non-Home parent, unused identity, absolute destination, and actual Git membership for an existing checkout. Primary, locked or replaced worktrees cannot be removed through the guarded path. Operation receipts reject token reuse with a different intent. Removal compares approved directory/device/inode/status/HEAD/branch inspection; the CLI requires `--force` for dirty removal, but the server protocol accepts an approved dirty inspection without a separate force flag.

Hooks require explicit opt-in and an unchanged approved command list. Setup runs machine then project hooks; teardown reverses that order. Setup failure keeps the newly registered checkout; teardown failure stops removal, although sessions/processes may already be stopped. Interrupted hooks are not automatically rerun. Enforcement: [crates/murvix-server/src/git/worktree.rs:35–253,299–498](../../crates/murvix-server/src/git/worktree.rs#L35-L253), [crates/murvix-server/src/git/hooks.rs:28–162](../../crates/murvix-server/src/git/hooks.rs#L28-L162), CLI policy [crates/murvix-cli/src/manage/projects.rs:385–419](../../crates/murvix-cli/src/manage/projects.rs#L385-L419). **Limit:** receipts/compensation do not make shell/Git/catalog/process side effects atomic. Pruning an externally missing empty worktree is a separate conditional no-op path, [crates/murvix-server/src/catalog/mutations.rs:171–190](../../crates/murvix-server/src/catalog/mutations.rs#L171-L190).

## BR-04 Session creation and operation identity

**Observed — replay rule:** a creation operation reserves membership/receipt before spawning. Matching retry compares project and initial directory, returns the original session information, and does not respawn an ended, unavailable or discarded session; requested dimensions/colors are not part of receipt equality. A cancellation recorded before creation prevents later creation with that token; cancellation after reservation discards the resolved session. Failed Live publication stops the newly started process; failed spawn records unavailable state.

Enforcement: [crates/murvix-server/src/registry.rs:444–589,629–634](../../crates/murvix-server/src/registry.rs#L444-L589), [crates/murvix-server/src/catalog/sessions.rs:21–120,160–167](../../crates/murvix-server/src/catalog/sessions.rs#L21-L120). **Limit:** recovery of a Starting reservation preserves identity, not a running PTY. Catalog persistence can return an error after rename committed state; receipts plus durability synchronization support retry, not “error means no mutation.” [crates/murvix-server/src/catalog/mod.rs:260–295](../../crates/murvix-server/src/catalog/mod.rs#L260-L295), [crates/murvix-server/src/catalog/storage.rs:7–43](../../crates/murvix-server/src/catalog/storage.rs#L7-L43).

## BR-05 Close, detach and session references

**Observed — shared-session policy:** a tokenized close preserves a session still referenced by its requester; otherwise it detaches requester channels and discards only if no connected participant preserves it via explicit references, pending creation or unreleased attachments. The decision is recorded and replayed rather than recalculated. Disconnect and detach alone do not end sessions. Explicit end/discard/project deletion bypass reference-aware close and can affect every viewer. End retains saved content; discard removes it.

Enforcement: [crates/murvix-server/src/registry.rs:619–626,675–799](../../crates/murvix-server/src/registry.rs#L675-L799), [crates/murvix-server/src/connection/outbox.rs:195–223,591–607](../../crates/murvix-server/src/connection/outbox.rs#L195-L223). **Limit:** disconnected saved layouts do not protect a session; reference/owner state is connection memory. Desktop close defaults/confirmation can be changed; nonshell foreground work can trigger confirmation, while detach skips termination. The explicit End All Sessions and Quit action does not add a confirmation prompt: [crates/murvix-app/src/model.rs:1133–1231,1325–1428](../../crates/murvix-app/src/model.rs#L1325-L1428).

## BR-06 Output retention, history and input acknowledgment

**Observed — retention policy:** ended/unavailable memberships become eligible after 604800 seconds (seven days), checked at startup and hourly, skipping live/starting handles. This is not deletion at an exact wall-clock instant. Output is checkpointed approximately one second after changes and finally on termination; processes are not restored after server restart. A crash/final-write failure can lose output. Archives and catalog are separate writes; retention can remove an archive before catalog cleanup succeeds.

Enforcement: [crates/murvix-server/src/catalog/retention.rs:7–33](../../crates/murvix-server/src/catalog/retention.rs#L7-L33), [crates/murvix-server/src/registry.rs:755–779](../../crates/murvix-server/src/registry.rs#L755-L779), [crates/murvix-server/src/run/retention.rs:3–30](../../crates/murvix-server/src/run/retention.rs#L3-L30), [crates/murvix-server/src/session/owner.rs:419–435,872–889](../../crates/murvix-server/src/session/owner.rs#L872-L889).

**Observed — implementation contract:** history is byte-budgeted, not a fixed row count; stale session/generation/query cursors fail instead of silently serving unrelated data. Saved history lacks live shell-prompt metadata. `WriteInput` acknowledges PTY write, not execution; timeout can mean input was already written. [crates/murvix-terminal/src/ghostty.rs:64–70](../../crates/murvix-terminal/src/ghostty.rs#L64-L70), [crates/murvix-server/src/archive.rs:195–249,406–502](../../crates/murvix-server/src/archive.rs#L195-L249), [crates/murvix-server/src/search.rs:10–163](../../crates/murvix-server/src/search.rs#L10-L163), [crates/murvix-server/src/session/owner.rs:223–253](../../crates/murvix-server/src/session/owner.rs#L223-L253). Desktop search permits one automatic stale restart, then asks the user to search again: [crates/murvix-app/src/views/terminal/find.rs:64–117](../../crates/murvix-app/src/views/terminal/find.rs#L64-L117).

## BR-07 Local view consistency and pin protection

**Observed — local constraints:** tab layout leaves must match pane IDs exactly; zoom/active references must be valid leaves. Removing the last pane closes its tab. Groups contain every tab exactly once, preserve order and select one member. Ratios are finite within 0.15–0.85. Desktop ordinary whole-tab/last-pane close refuses pinned tabs; bulk close excludes pins.

Enforcement: [crates/murvix-app-core/src/tab.rs:18–38,124–144](../../crates/murvix-app-core/src/tab.rs#L124-L144), [crates/murvix-app-core/src/groups.rs:135–173](../../crates/murvix-app-core/src/groups.rs#L135-L173), [crates/murvix-app-core/src/layout.rs:136–174](../../crates/murvix-app-core/src/layout.rs#L136-L174), [crates/murvix-app/src/model.rs:1133–1161,1325–1341](../../crates/murvix-app/src/model.rs#L1133-L1161). **Exceptions:** lower-level `AppState::close_tab` has no pin guard; confirmed project-layout replacement intentionally closes pins. Public mutable model fields and `store::save` do not enforce every UI invariant on every write. TUI uses different limits: 256 total panes, 64 tabs/project, 16 split panes/tab, [crates/murvix-cli/src/state.rs:12–16,170–223](../../crates/murvix-cli/src/state.rs#L170-L223).

## BR-08 Explicit project-layout application

**Observed — user policy and parser limits:** discover nonhidden YAML/YML/JSON files in `.murvix/layouts`; apply only after explicit desktop selection/confirmation. Configuration is at most 256 KiB, nesting at most 32, terminals at most 64. `vertical` means stacked; other supplied axis text falls back to horizontal in this parser rather than being universally rejected. Command arrays become ` && `-joined shell text. Legacy `tabs` adds extra top-level tabs.

Enforcement: [crates/murvix-app-core/src/project_layouts.rs:8–81,105–149,187–221](../../crates/murvix-app-core/src/project_layouts.rs#L8-L81). Confirmation checks project directory and tab/pane identity snapshot again, then replaces all project tabs including pins; unreferenced old sessions are queued for close. New panes/startup commands are persisted separately from later server creation/input. [crates/murvix-app/src/model/project_layouts.rs:253–359](../../crates/murvix-app/src/model/project_layouts.rs#L253-L359), [crates/murvix-app-core/src/project_layouts.rs:251–312](../../crates/murvix-app-core/src/project_layouts.rs#L251-L312). **Limit:** no cross-server transaction or exactly-once shell execution is established. The TUI does not load these project files; see [docs/product/product-model.md:120–146](../product/product-model.md#L120-L146).

## BR-09 Git review and destructive operations

**Observed — guarded-operation contract:** reviewed commit-all/staged requires unchanged expected HEAD/tree, named branch and no conflicts; commit-all attempts index restoration on failure. Reviewed publish checks branch/destination. **Bypass:** direct `Commit { stage_all }` does not require a reviewed snapshot. Legacy `DeleteBranch` forces deletion, whereas `DeleteLocalBranch { force }` selects safe/forced behavior.

Git discard refuses conflicts/staged-only paths and unsafe traversal; tracked edits restore worktree content, but untracked files are permanently removed, not sent to Trash. Empty stage/unstage means all, while empty discard does nothing. Enforcement: [crates/murvix-server/src/git/snapshot.rs:74–209](../../crates/murvix-server/src/git/snapshot.rs#L74-L209), [crates/murvix-server/src/git/mutate.rs:7–46](../../crates/murvix-server/src/git/mutate.rs#L7-L46), [crates/murvix-server/src/git/mod.rs:240–257,332–415](../../crates/murvix-server/src/git/mod.rs#L332-L415).

**Observed — AI/PR limits:** AI generation may leave staging changed on failure; application uses expected head/tree but commits/pushes/PR creation are not atomically rolled back. Current flow applies parsed generated metadata without a second generated-draft review UI, despite settings text saying otherwise. [crates/murvix-app/src/repository_actions.rs:216–300,577–745](../../crates/murvix-app/src/repository_actions.rs#L216-L300), [crates/murvix-app/src/model/ai.rs:493–514](../../crates/murvix-app/src/model/ai.rs#L493-L514). GitHub failures can leave a pushed branch, created PR or local merge; fork/update/head checks apply only to their named operations: [crates/murvix-server/src/git/github.rs:20–326](../../crates/murvix-server/src/git/github.rs#L20-L326).

## BR-10 Connection authority

**Observed — access policy:** ordinary local/SSH-bridged clients and device-authenticated TLS connections differ. Paired clients may operate terminals/projects/Git/files/uploads and read settings, but cannot administer pairing, stop server, write server settings, use dedicated exec/cancel, or claim a desktop/TUI/CLI identity. This is **not a shell sandbox**.

Pairing requires enabled listening, a one-use offer expiring after 300 seconds, and local approval; a new offer replaces the old, owner disconnect cancels it, maximum paired devices is 64. Disable preserves credentials/identity but disconnects devices; revoke persists removal then closes affected connections. Corrupt access state fails closed; explicit enable can replace unreadable state with new defaults/identity. Enforcement: [crates/murvix-server/src/connection/policy.rs:7–74](../../crates/murvix-server/src/connection/policy.rs#L7-L74), [crates/murvix-server/src/remote/mod.rs:166–352](../../crates/murvix-server/src/remote/mod.rs#L166-L352), [crates/murvix-server/src/registry.rs:315–359](../../crates/murvix-server/src/registry.rs#L315-L359). **Limit:** SSH authorization is external account access, not pairing; no phone application ships here. Browser socket authority is separate in BR-14.

## BR-11 Draft and submission preservation

**Observed — store invariant:** file attachments must be absolute; image numbers are positive/unique, correspond to placeholders and valid filenames, and next number exceeds existing numbers. Malformed drafts/profile-lock failures block edits to preserve data. **Observed — delivery policy:** nonblank selection submits only selected text, not normal file attachments. Broadcast targets visible live terminals and deduplicates server/session pairs; stale target checks protect delivery. Partial broadcast preserves draft and reports completed targets; successful clear uses original revision so intervening edits survive. Earlier PTY writes/uploads cannot be undone.

Enforcement: [crates/murvix-app-core/src/composer/draft.rs:80–105,243–280,334–477](../../crates/murvix-app-core/src/composer/draft.rs#L80-L105), [crates/murvix-app-core/src/composer/submission.rs:43–121](../../crates/murvix-app-core/src/composer/submission.rs#L43-L121), [crates/murvix-app/src/model/composer.rs:775–953](../../crates/murvix-app/src/model/composer.rs#L775-L953). **Limit:** input acknowledgment is not command success; image retention is not permanent attachment storage. Dictation and another active submission suppress sending. Unexecuted preservation scenarios: [crates/murvix-app/src/model/tests/composer.rs:78–207](../../crates/murvix-app/src/model/tests/composer.rs#L78-L207).

## BR-12 Extension authority

**Observed — permission and consent:** registered owner/document/epoch establishes call identity, then declared permission and sensitive-operation consent apply. Remembered grant rules are scoped; unreadable grants fail closed. Consent expires after 60 seconds, at most five pending/displayed prompts per extension. Gates cover exec, terminal interaction, foreign extension tabs, startup commands, Git/file writes, HTTP and project deletion; browser automation is permission-controlled but not covered by those consent gates. `foundation` debug owner is an explicit authorization exception.

Enforcement: [crates/murvix-app-core/src/extensions/permissions.rs:43–151,209–342,347–510](../../crates/murvix-app-core/src/extensions/permissions.rs#L43-L151), [crates/murvix-app/src/model/extensions/mod.rs:744–938](../../crates/murvix-app/src/model/extensions/mod.rs#L744-L938), [crates/murvix-app/src/model/extensions/consent.rs:14–18,145–395](../../crates/murvix-app/src/model/extensions/consent.rs#L145-L395). Host HTTP restricts destination access; ordinary browser navigation/automation is not the same HTTP bridge. [crates/murvix-app/src/extensions/http.rs:1–210](../../crates/murvix-app/src/extensions/http.rs#L1-L210).

**Observed — admission/lifecycle:** resources must remain within canonical package root; native pages restrict bridge origin/document and assets. Marketplace checks HTTPS origin, exact size/hash and manifest metadata, not publisher signing. Permission-expanded updates remain disabled for review; unpacked unload preserves developer files. Before-close checks have explicit panel/popover/lifecycle bypass paths and are not universal cancellation rights. [crates/murvix-app-core/src/extensions/manifest.rs:468–740](../../crates/murvix-app-core/src/extensions/manifest.rs#L468-L740), [crates/murvix-ui/src/webview/rules.rs:1–65](../../crates/murvix-ui/src/webview/rules.rs#L1-L65), [crates/murvix-app/src/extensions/marketplace.rs:70–263,288–349](../../crates/murvix-app/src/extensions/marketplace.rs#L70-L263), [crates/murvix-app/src/model/extensions/updates.rs:8–141](../../crates/murvix-app/src/model/extensions/updates.rs#L8-L141), [crates/murvix-app/src/model/webviews/panels.rs:152–212](../../crates/murvix-app/src/model/webviews/panels.rs#L152-L212). **Not established:** complete native-engine/network sandboxing.

## BR-13 File, upload and exec constraints

**Observed — distinct scopes:** project-relative file traversal rejects root escape; internal symlinks may resolve safely. Read/write limit is 5 MiB; only regular files may be read/overwritten. Batch overlapping selections are rejected before sequential mutation, not made transactional. File Delete uses OS Trash, unlike Git discard. List hiding `.git` is not a universal prohibition on `.git` mutation. [crates/murvix-server/src/files/root.rs:35–163](../../crates/murvix-server/src/files/root.rs#L35-L163), [crates/murvix-server/src/files/operations.rs:17–271](../../crates/murvix-server/src/files/operations.rs#L17-L271), [crates/murvix-server/src/files/trash.rs:1–65](../../crates/murvix-server/src/files/trash.rs#L1-L65).

Uploads require a live or saved catalog session, ordered offsets and at most 100 MiB/file in at most 1 MiB chunks; store in private per-session temporary space and return a path, without typing it. Exec may override cwd outside the project, permits at most 32 jobs/connection and 300000 ms timeout, bounds stdin/stdout/stderr and kills process groups on cancellation/disconnect/timeout. It is not persistent session creation or project confinement. [crates/murvix-server/src/uploads.rs:18–138](../../crates/murvix-server/src/uploads.rs#L18-L138), [crates/murvix-protocol/src/upload.rs:7–60](../../crates/murvix-protocol/src/upload.rs#L7-L60), [crates/murvix-server/src/exec.rs:38–122,258–383](../../crates/murvix-server/src/exec.rs#L38-L122). **Not established:** atomic file batches, permanent temporary-upload retention or universal cancellation of exec on project deletion.

## BR-14 Browser scope and profiles

**Observed — desktop authority:** browser `tabId` identifies a pane; operations are desktop-local even for a remote project. Local `app.sock` has mode 0600 and accepts only `browser.*`, without extension permission/consent checks. Extension browser calls need read/write permission but do not use HTTP-host consent; authenticated pages/cookies are within browser authority. **Not established:** peer-credential checks beyond filesystem access.

Disabled browser lists empty but other operations fail; saved pane records remain. Default profile cannot be deleted; deleting another retargets panes to default. URL/profile persist, not title/zoom/back-forward history. Most waits are bounded, but native screenshot/cookie callbacks do not share one universal script timeout. [crates/murvix-app/src/app_socket.rs:1–109](../../crates/murvix-app/src/app_socket.rs#L1-L109), [crates/murvix-app/src/model/browsers/automation.rs:27–118,119–389](../../crates/murvix-app/src/model/browsers/automation.rs#L119-L389), [crates/murvix-app/src/model/browsers/profiles.rs:123–398](../../crates/murvix-app/src/model/browsers/profiles.rs#L123-L398). **Limit:** profile deletion/clear is not established as atomic across native storage and pane updates.

## BR-15 Configuration restore and exclusions

**Observed — backup policy:** restore concerns configuration and local project layouts, not process/session resurrection. Backup excludes project files, live sessions, composer drafts/images, browser profile data, extension packages and paired credentials; settings may retain remote endpoints but not remote project snapshots. Native restore preserves existing projects and replaces matching layouts; legacy merge preserves existing details/tabs. Complete restore resets omitted allowed roots; partial/merge changes included roots only.

Enforcement: [crates/murvix-app/src/backup/mod.rs:19–55,187–303,470–549](../../crates/murvix-app/src/backup/mod.rs#L19-L55), [crates/murvix-app-core/src/backup/projects.rs:15–210](../../crates/murvix-app-core/src/backup/projects.rs#L15-L210). Import validation rejects unsafe ZIP paths/symlinks/duplicates and unresolved terminal-config includes; schema and bounded sizes are checked. [crates/murvix-app/src/backup/archive.rs:12–260](../../crates/murvix-app/src/backup/archive.rs#L12-L260).

**Observed — consistency limit:** normal confirmation stages next-launch restore; startup journal/recovery snapshots compensate sequential root replacements. Recovery failure refuses known-partial profile loading, not a claim of atomic multi-file/power-loss-proof restore. Installed legacy-project import can merge immediately; installed legacy-extension migration is an explicit package-copy exception. [crates/murvix-app/src/backup/transaction.rs:24–236](../../crates/murvix-app/src/backup/transaction.rs#L24-L236), [crates/murvix-app/src/model.rs:904–925](../../crates/murvix-app/src/model.rs#L904-L925), [crates/murvix-app/src/backup/extensions.rs:23–83,117–229](../../crates/murvix-app/src/backup/extensions.rs#L117-L229).

## BR-16 Safe executable replacement

**Observed — compatibility policy:** installed release updates distinguish protocol compatibility from equal app version. Preserve requires shared protocol; WhenIdle uses atomic stop-if-idle; EndSessions stops processes before app replacement. Fresh server identity/build checks prevent replacing an unexpected server. Replacement failure cannot resurrect terminated processes. Linux package-manager locations are not replaced by the user-managed updater.

Enforcement: [crates/murvix-app/src/model/updates.rs:485–691](../../crates/murvix-app/src/model/updates.rs#L485-L691), [crates/murvix-app/src/server.rs:67–180](../../crates/murvix-app/src/server.rs#L67-L180), [crates/murvix-app/src/updater/linux.rs:1–170](../../crates/murvix-app/src/updater/linux.rs#L1-L170). Linux activation verifies complete package/build identities and preserves runtime leases; macOS checks signing/bundle/helper identity and keeps prior bundle for attempted rollback. [scripts/install-desktop-linux.py:122–300](../../scripts/install-desktop-linux.py#L122-L300), [crates/murvix-app/src/updater/macos.rs:231–282,323–410](../../crates/murvix-app/src/updater/macos.rs#L231-L282). **Not established:** published assets/feed, platform signing or semantic health after restart; the Linux helper observes launch/early exit, not workspace correctness.

## BR-17 Agent attention and notification claims

**Observed — heuristic/transient policy:** provider identity comes from foreground processes; working/blocked/idle comes from title/screen/progress heuristics. Completion requires a previously seen working cycle and stable idle evidence; blank redraw is not completion proof. Activity is memory-only, at most one unread event/session, global cap 200; acknowledgement deletes events. End removes status and attention; clearing provider detection can leave attention.

Only the first registered live Desktop connection receives claim opportunities; claim is not acknowledgement or proof the OS displayed a notification. Desktop further suppresses focused/nonparticipating sessions. [crates/murvix-server/src/detection/mod.rs:138–257](../../crates/murvix-server/src/detection/mod.rs#L138-L257), [crates/murvix-server/src/activity.rs:23–35,79–159](../../crates/murvix-server/src/activity.rs#L79-L159), [crates/murvix-server/src/registry.rs:636–659](../../crates/murvix-server/src/registry.rs#L636-L659), [crates/murvix-app/src/model/activity.rs:159–263,310–421](../../crates/murvix-app/src/model/activity.rs#L159-L263). **Not established:** durable notification history, exactly-once display, or actual agent task success.

## BR-18 Personalization, locale and platform availability

**Observed — capability/validation policy:** runtime support distinguishes unsupported backend from unavailable dependency/service. Quick Terminal is local Home work; Linux global shortcut rejects Wayland. Custom commands are user-controlled single-line shell text under 64 KiB, with validated unique IDs/names and shortcut conflicts checked on relevant settings paths. Localization providers must be enabled, stay within bundle paths, preserve format placeholders and omit `CFBundleExecutable`; missing provider falls back to English.

Enforcement: [crates/murvix-core/src/capability.rs:63–94,119–127](../../crates/murvix-core/src/capability.rs#L63-L94), [crates/murvix-ui/src/quick_terminal/platform/linux/shortcut.rs:67–95](../../crates/murvix-ui/src/quick_terminal/platform/linux/shortcut.rs#L67-L95), [crates/murvix-app-core/src/settings/commands.rs:29–110](../../crates/murvix-app-core/src/settings/commands.rs#L29-L110), [crates/murvix-app-core/src/localization.rs:94–169](../../crates/murvix-app-core/src/localization.rs#L94-L169), [crates/murvix-app/src/model/language.rs:14–60](../../crates/murvix-app/src/model/language.rs#L14-L60). **Limits:** no global settings transaction; localization's key check is not proof every unused executable file is scanned; native services/tools/permissions require runtime prerequisites not inspected here.
